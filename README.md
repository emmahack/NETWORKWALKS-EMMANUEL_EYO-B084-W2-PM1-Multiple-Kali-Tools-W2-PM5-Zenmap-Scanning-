## Week 2: Network Reconnaissance and Host Discovery

As part of my cybersecurity internship with Networkwalks, I completed an introductory, authorized reconnaissance exercise.

### What I worked on

- Reviewed public DNS and website information for `networkwalks.com`.
- Used tools including WHOIS, WhatWeb, Nslookup, Curl, WAFW00F, and DNSRecon.
- Identified my local Wi-Fi subnet and found two live hosts  during an authorized Nmap ping scan. 
- Recorded the evidence, observations, limitations, and recommendations in a pentest report.

### Key takeaway

The scan identified two live hosts on the local subnet. The collected web and DNS details are reconnaissance observations and should be independently validated; this exercise did not include exploitation or vulnerability confirmation.

### Tools

`Nmap` · `Zenmap` · `WHOIS` · `WhatWeb` · `Nslookup` · `Curl` · `WAFW00F` · `DNSRecon`

This work was conducted as part of an internship learning exercise. Network scanning should only be performed on systems and networks you own or have explicit permission to assess.
